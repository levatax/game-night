# Contract changes (append-only)

The shared contracts (`shared/constants.ts`, `shared/maps.ts`, `shared/protocol.ts`,
`shared/types.ts`, `server/schema.ts`) and the architect-written files listed in
`docs/ARCHITECTURE.md` §0 are frozen while builders work in parallel. If you need a change,
do NOT edit them: work around it inside your own folder (local constant, adapter, extra field
in your own types) and append one line below so the integrator can reconcile it later.

Format: `- [role] file: what you need changed and why (where your workaround lives).`

- [server] server/world/events.ts: `BroadcastWorldEvent` for powerUpWarning/powerUpSpawn/powerUpPickup was uninhabitable (the payload's own `type: PowerUpType` intersected with the `type` discriminator → never). Those three world events now carry the power-up kind as `powerUpType`, and the new `toMessage(ev)` rebuilds the exact protocol payload (`type: PowerUpType`) that BonkRoom broadcasts. Wire format unchanged; only server-internal typing.
- [client-audio] client/src/audio/AudioEngine.ts: PlayOptions says "HRTF on high quality, equalpower otherwise", but the engine has no quality input. Added `AudioEngine.setSpatialQuality(hrtf: boolean)` (default HRTF); client-app may call `audio.setSpatialQuality(s.quality !== "low")` where it applies the `quality` setting in App.applySettings. Optional: without it every quality level uses HRTF.
- [sim] physics redesign (additive, no PROTOCOL_VERSION exists, none introduced): `shared/constants.ts` physics block — GROUND_ACCEL 48, GROUND_DECEL 40, AIR_CONTROL and STUN_GROUND_DECEL removed (→ AIR_ACCEL/AIR_DECEL, FrictionProfile.knockSlideDecel), JUMP_VELOCITY 7.48 + variable-jump gravity mults, KNOCKBACK 5.6/3.6, SHOCKWAVE 7.5/4.5, HEADBUTT 10.5/5.5, new KNOCK_*/TUMBLE_*/DI_*/BUMP_*/BALL_DEATH_*/BALL_ROLL_DRAG/SKID_MIN_SPEED/PREDICTION_KNOCK_*, BALL_ROLL_DECEL 3, BALL_BOUNCE_FRICTION 0.75; `shared/maps.ts` FrictionProfile + groundBrake/groundGrip/knockSlideDecel/ballRestitution and a STICKY (Cake) profile; `shared/types.ts` PlayerSimFields + jumping/skid/knockBounces (PlayerAction unchanged); `shared/protocol.ts` BTN.JUMP_HELD = 32 (level bit, not in EDGE_BUTTONS), MSG.BUMP + BumpEvent (ServerMessages/WorldEventType), HitEvent/HeadbuttEvent.launchSpeed, ShockwaveEvent.knockbacks; `server/schema.ts` PlayerState jumping/skid/knockBounces (46 fields); `server/world/inputs.ts` BUTTON_MASK 63. Callers updated: Net SERVER_MESSAGES, Input.sample (JUMP_HELD), room/GameController test fixtures.
- [client-characters] character redesign (client-only, no shared/** or protocol change): `client/src/characters/faces.ts` sheet is now 1024×512 (4×2 cells of 256², no squeeze) — `FACE_SHEET_SIZE` = sheet WIDTH (1024), new `FACE_SHEET_HEIGHT` = 512, new `setFaceOffset(texture, expr)`; `Animal` gains `setFaceParts(eyes, mouth)` (setExpression(e) = setFaceParts(e, e)), optional ctor `opts.detail` ("hi" | "mid"), `AnimalParts` gains springs/earR/earL/tail/headwear/cheeks/eyeBulbs (new `characters/rigTypes.ts` SpringBone), `parts.belly` is Mochi's Group pivot (null otherwise); `parts.ts` builder is batched (one merged mesh + outline per pivot, `finish()`), `OUTLINE_THICKNESS` 0.022 + `OUTLINE_THICKNESS_ACCESSORY` 0.015. Callers updated: dev harness, Memento, MenuCrowd, CharacterPreview. AnimalRig unchanged.
